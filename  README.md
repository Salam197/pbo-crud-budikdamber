Aplikasi ini bertujuan sebagai alat atau media untuk melakukan pemonitoringan budikdamber dan akuaponik secara mandiri menggunakan media web. Disini kita dapat membuat hinga mengedit ember yang berisi kapasitas, jenis ikan, tananam yang ditanam diatas bak ikan terseut lalu kita juga dapat memberikan kapan benih akan di tebar. Lalu ada juga fitur form pengisian sebgai pencatatan harian pemeliharaan ikan dan tanaman di media akuaponik
Proyek " Monitoring Budikdamber & Akuaponik" ini memiliki lima class yaitu Database, BaseModel, Bucket, DailyLog dan Helper. Konsep 'inheritance' diterapkan dengan BaseModel menjadi parent class yang diwarisi child class Bucket dan DailyLog untuk berbagai fungsi dasar seperti pencarian dan penghapusan data berdasarkan ID. Untuk hak akses private digunakan pada class Database untuk menyembunyikan komposisi host, nama database, dan kredensial PDO lalu hak akses protected dipakai pada properti koneksi($db) dan nama tabel ($table) di dalam BaseModel agar tetap bisa diakses oleh kelas turunannya. Sementara itu, public digunakan pada seluruh metode operasi CRUD dan koneksi, serta metode static diletakkan pada class Helper (clean() dan statusAirColor()) agar fungsi sanitasi input dan penentuan warna status air dapat dipanggil langsung tanpa instansiasi objek.
Pada sisi database (db_budikdamber), terdapat hubungan One-to-Many antara tabel induk buckets yang menyimpan data unit ember dan tabel anak daily_logs yang menyimpan catatan pemeliharaan harian. Keduanya terhubung melalui kolom bucket_id sebagai Foreign Key yang merujuk pada id di tabel buckets dengan aturan ON DELETE CASCADE, sehingga penghapusan satu unit ember otomatis menghapus riwayat harian yang terkait. Untuk menjalankan aplikasi secara lokal, impor terlebih dahulu skema SQL dari file database.sql ke MySQL/MariaDB, lalu jalankan perintah php -S localhost:8000 -t public melalui terminal di direktori utama proyek dan akses http://localhost:8000 di browser.
